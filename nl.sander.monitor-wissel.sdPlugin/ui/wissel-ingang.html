Laat G HUB de G-toets deze functietoets sturen; de plugin luistert er zelf naar.
Staat het scherm op de thuisingang, dan gaat het naar de werkingang; in elk ander geval naar de thuisingang. Een handmatige code overstemt de keuzelijst. Geheugenstand is nodig voor schermen die over de pc-kabel altijd dezelfde ingang melden (zoals de HP E273q). Met een Sneltoetsnaam wisselt deze knop ook via de deep link streamdeck://plugins/message/nl.sander.monitor-wissel/wissel/<sneltoetsnaam>?streamdeck=hidden (bijvoorbeeld vanuit AutoHotkey), zolang de knop op de huidige pagina staat.
